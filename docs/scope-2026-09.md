# 範圍裁定（2026-09-16）：收斂到跨廠任務信箱，凍結周邊

> 本檔是決策記錄，不是使用說明。逐命令分類表由 `tests/check-contract.sh 5`
> 機器核對：`spec/cli.md` 的每個子指令章節在下表恰出現一次。

## 裁定

使用者裁定（2026-09-16）：**方向 A**——Rust 核心維護；`ui`／`scan`／`gc`／
`relay` 凍結；同廠（claude→claude）的純對話改用 Claude Code 內建的跨 session
訊息，不再由本專案承接。

「凍結」的定義：只修**違反既有 spec 契約**的故障（容許修正契約的描述文字），
不新增行為承諾、不接新功能；既有測試分組照跑，不刪。解凍條件：使用者舉出
**一個必須用它才能完成的真實工作流程**並附驗收條件，記入本檔，**且使用者
明確核准**後才恢復擴充；舉例與記錄本身不等於核准。

不做：重寫回 bash（協定複雜度不隨語言消失）；砍到只剩 sender 五條命令
（worker 端沒有 receive／reply／fail 就跑不完協定，等於偷偷重建隱藏協定）；
與同廠原生通道競爭。

## 逐命令分類

三類：**keep**＝跨廠任務協定的必經路徑（每個 task 都走），或有使用計數；
**support**＝非必經、無獨立計數，但拿掉會破壞核心協定或既定回收流程；
**freeze**＝依上節定義凍結。

| 子指令 | 分類 | 依據 |
|---|---|---|
| `send` | keep | 736 task |
| `receive` | keep | 必經：worker 端取件入口 |
| `reply` | keep | 688 completed |
| `fail` | keep | 2 failed；worker 端誠實失敗路徑 |
| `read` | keep | 必經：sender 端取回覆 |
| `await` | keep | 必經之一：派工紀律要求背景 await；codex worker 發不出通知時 sender 靠 await 或 status 輪詢取終態 |
| `status` | keep | 必經之一：await 之外的輪詢路徑；cancel 通知 worker 的落點 |
| `cancel` | keep | 30 cancelled |
| `spawn` | keep | 249 次 |
| `despawn` | keep | 99 despawned＋146 despawned-unsaved 事件（含 evict 第三段） |
| `evict` | keep | 72 次 |
| `disposable` | keep | 5 次宣告；idle／evict 挑選順序依賴它 |
| `ask` | keep | 2026-09-17 立案：send→await→read 組合，只組三個 keep 指令；量測（agents.log＋tasks，2026-07-22～09-17）212 次 spawn 收 714 task、每次 spawn 平均 3.37 個，一問一答且留 worker 追問是主流形狀 |
| `register` | support | reverse send 要 orchestrator 先註冊自己；39 個 task 的收件者對不到 spawn 紀錄 |
| `unregister` | support | register 的逆操作 |
| `list` | support | 派工前查 ready；`list --long` 是人工介入視圖 |
| `start` | support | 可選；讓 status 分得出 delivered 與 running |
| `ready` | support | spawn 就緒探針的落地端，不可拆 |
| `hook` | support | busy 延後通知（HOOK-NOTIFY）依賴 Stop hook 取件；拆掉會改變派工可靠性 |
| `idle` | support | orchestrator-brief 指定的回收前查池視圖；`list --long` 共用同一計算 |
| `relay` | freeze | 裁定當下使用量無法判定，之後審計記 `relayed` 可計數；使用者自述以手動貼交接為主。解凍條件同上 |
| `ui` | freeze | 13,343 行、使用未知、理解驗收 1/3 未過（README.zh-TW 已知限制） |
| `scan` | freeze | 每個成功的非唯讀指令（排除 ui、scan 自身）順手掃，故無手動使用證據；推播效益未知 |
| `gc` | freeze | 無呼叫紀錄、無磁碟壓力數據；工具暫留 |
